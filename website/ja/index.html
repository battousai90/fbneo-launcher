エミュレーター FinalBurn Neo のために

FBNeo Launcher はフロントエンドです。ROM セットを見つけ、検証し、整理したうえで FinalBurn Neo に渡し、実際のエミュレーションはそちらが担います。エミュレーターは独自のチームによる別プロジェクトで、本ランチャーから最新版をダウンロードできます。

Linux版ではさらに一歩踏み込んでいます。FinalBurn Neo本家チームはSDL2/Linux版のメンテナンスを終了しており、一部のシステム（Game Boy Advance、Bally Astrocade）ではゲームリストの生成が気づかぬうちに止まっていました。私たちは彼らのリポジトリを毎日追跡し、この修正を加えた独自ビルドを公開しているので、すべてのシステムが最初からカバーされます。

ROM 管理

RomVault 風のワークフローを内蔵

すべての ROM は CRC32 を再計算し、FinalBurn Neo の公式 DAT ファイルと照合して検証します。ファイル名や書庫に記録された値を信用することはありません。

  • DAT の CRC 照合で ROM の整合性を監査
  • 不足・破損・不完全な ROM を検出
  • 既存のライブラリからセットを自動的に再構築
  • ROM を再帰的にインポート
  • 不足 ROM レポートと監査レポートを生成
  • クローン / 親情報を DAT からそのまま表示
  • ライブラリ内の重複 ROM を検出
  • 出力に入る前にすべてのセットを検証

📀

本物の CRC 検証

すべての書庫のすべてのエントリーを展開して CRC32 を再計算し、DAT と照合します。破損した書庫が正常を装うことはできません。

🔬

ライブラリ監査

どのセットが壊れていてどのファイルが原因かを、4 つの明確な判定で示します。

  • OK — 名前もデータも正しい
  • 名前違い — データは正しいが名前が違う
  • 破損 — 存在するが内容が誤り
  • 欠落 — セットに存在しない
📥

受信箱 → 送信箱の再構築

ダウンロードを受信フォルダーに置いて「解析」を押すだけ。完全なセットは移動され、壊れたセットはダウンロード内および既存ライブラリ内で見つかった部品から再構築されます。

🛡️

ライブラリには一切書き込みません

ライブラリは読み取り専用の部品置き場としてのみ使われます。結果は DAT の構成を写した別の出力フォルダーに置かれるので、最悪でも削除すれば済みます。

🗜️

zip・7z・rar・tar

ダウンロードしたものをそのまま読み込みます。ソリッド圧縮の 7z も一度の走査で取り出します。書き出しは常にフラットでクリーンな ZIP セット — エミュレーターが読める唯一の形式です。

⚡

差分スキャン

内容アドレス方式のキャッシュを備えたローカル SQLite データベース。再スキャンはサイズや更新日時が変わったファイルのみを対象とし、DAT 更新時も実際に変わったセットだけを再確認します。

📋

書き出せるレポート

不足 ROM の一覧や監査結果をシステム別に整理したテキストレポートとして保存。まだ必要なファイルの CRC とサイズも記載されます。

🔄

DAT ツール

FinalBurn Neo の実行ファイルから DAT を生成し、データベースを更新し、FBNeo の最新版をダウンロード — すべてアプリ内で完結します。

Linux ゲーミング PC と SteamOS

リビングにもなじむ

Linux のゲーミングマシンと、ソファの前の SteamOS 機のために作られています。キーボードとマウスで操作する本物のデスクトップ画面、そしてゲーム本体にはコントローラーを。

🎮

SteamOS と Steam Machine（Steam Box）

SteamOS は Arch ベースでシステム領域が読み取り専用のため、デスクトップソフトの導入方法として Flatpak が正式にサポートされています。Flatpak バンドルはデスクトップモードにそのまま導入でき、システムのロック解除も pacman も不要です。

🕹️

探すのはキーボードとマウス、遊ぶのはパッド

25,000 本から探すのはキーボードの仕事です。ランチャーはそれを前提に作られています。ゲームはジョイスティック対応を有効にした状態で起動し、コントローラープロファイルは保存して再利用できます。

📺

一覧からゲームまで 2 クリック

入れ子のメニューをかき分ける必要はありません。検索し、クリックし、遊ぶだけ。Steam に非 Steam ゲームとして追加すれば、ゲームモードからも起動できます。

ソースから

Debian / Ubuntu なら 3 コマンド

# 1 — dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 — build
git clone https://github.com/battousai90/fbneo-launcher.git
cd fbneo-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 — run
cd build && ./fbneo-launcher

パッケージが欲しいですか？ ./scripts/package.sh が AppImage・.deb・tar アーカイブ・Flatpak バンドルを dist/ に生成します。リリースワークフローが実行するのとまったく同じスクリプトです。
