Feito para o emulador FinalBurn Neo

O FBNeo Launcher é uma interface: encontra, verifica e organiza os teus conjuntos de ROMs, e depois entrega-os ao FinalBurn Neo, que trata da emulação. O emulador é um projeto separado, com a sua própria equipa — o lançador pode descarregar a versão mais recente por ti.

No Linux vamos um pouco mais além: a própria equipa do FinalBurn Neo já não mantém a versão SDL2/Linux, que tinha deixado de gerar silenciosamente as listas de jogos de alguns sistemas (Game Boy Advance, Bally Astrocade). Acompanhamos o repositório deles diariamente e publicamos a nossa própria compilação com essa correção, para que todos os sistemas fiquem cobertos desde o início.

Gestão de ROMs

Um fluxo ao estilo RomVault, integrado

Cada ROM é verificada recalculando o seu CRC32 face aos ficheiros DAT oficiais do FinalBurn Neo — nunca confiando num nome de ficheiro ou no valor guardado no arquivo.

  • Audita a integridade das ROMs através da verificação CRC dos DAT
  • Deteta ROMs em falta, corrompidas ou incompletas
  • Reconstrói os conjuntos automaticamente a partir da sua biblioteca existente
  • Importa ROMs de forma recursiva
  • Gera relatórios de ROMs em falta e de auditoria
  • Mostra a informação de clone / pai diretamente do DAT
  • Encontra ROMs duplicadas na sua biblioteca
  • Cada conjunto é verificado antes de chegar à saída

Verificação CRC real

Cada entrada de cada arquivo é descomprimida e o seu CRC32 recalculado, e depois confrontado com o DAT. Um arquivo corrompido não se pode fazer passar por válido.

🔬

Auditoria da biblioteca

Diz-te quais conjuntos estão danificados e que ficheiro tem culpa, com quatro veredictos distintos.

  • OK — nome certo, dados certos
  • Nome errado — dados certos, mal nomeado
  • Corrompido — presente mas com conteúdo errado
  • Ausente — nem sequer está no conjunto
📥

Reconstrutor entrada → saída

Deixa as tuas transferências numa pasta de entrada e carrega em Analisar. Os conjuntos completos são deslocados, os danificados reconstruídos a partir de peças encontradas nas tuas transferências e na tua biblioteca atual.

🛡️

A tua biblioteca nunca é alterada

Serve apenas como reserva de peças, em leitura. Os resultados vão para uma pasta de saída separada que reproduz a estrutura dos DAT: no pior caso, uma pasta que podes apagar.

🗜️

zip, 7z, rar, tar

Lê o que quer que tenhas descarregado — incluindo arquivos 7z sólidos, esvaziados numa só passagem. Escreve sempre conjuntos ZIP limpos e planos, o único formato que o emulador carrega.

⚡

Análise incremental

Uma base SQLite local com cache endereçada por conteúdo. As reanálises só tocam nos ficheiros cujo tamanho ou data mudou; uma atualização de DAT só reverifica os conjuntos realmente alterados.

📋

Relatórios exportáveis

Guarda a lista de ROMs em falta ou a auditoria completa como relatório de texto, agrupado por sistema, com o CRC e o tamanho de cada ficheiro que ainda te falta.

🔄

Ferramentas DAT

Gera os ficheiros DAT a partir do teu binário do FinalBurn Neo, atualiza a base de dados ou descarrega a versão mais recente do FBNeo — tudo a partir da aplicação.

PCs de jogos Linux e SteamOS

À vontade na sala

Feito para máquinas de jogo Linux e sistemas SteamOS de sala: uma verdadeira interface de ambiente de trabalho, conduzida com teclado e rato, com o comando pronto para o jogo em si.

🎮

SteamOS e Steam Machine (Steam Box)

O SteamOS assenta em Arch com uma partição de sistema só de leitura, por isso o Flatpak é a via de instalação suportada para software de ambiente de trabalho. O pacote Flatpak instala-se diretamente no modo Ambiente de Trabalho, sem desbloquear o sistema nem mexer no pacman.

🕹️

Teclado e rato para percorrer, comando para jogar

Procurar entre 25 000 jogos é trabalho de teclado, e é nisso que o lançador assenta. Os jogos arrancam com o suporte de joystick já ativo, e os perfis de comando são guardados e reutilizados.

📺

Dois cliques da lista ao jogo

Sem menus encaixados para atravessar: procura, clica, joga. Adiciona o lançador ao Steam como jogo externo e fica acessível a partir do modo Jogo.

A partir do código

Três comandos em Debian ou Ubuntu

# 1 — dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 — build
git clone https://github.com/battousai90/fbneo-launcher.git
cd fbneo-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 — run
cd build && ./fbneo-launcher

Preferes os pacotes? ./scripts/package.sh produz a AppImage, o .deb, o arquivo tar e o bundle Flatpak em dist/ — exatamente o script que o fluxo de publicação executa.
