สร้างขึ้นเพื่อโปรแกรมจำลอง FinalBurn Neo

FBNeo Launcher เป็นส่วนหน้า: ทำหน้าที่ค้นหา ตรวจสอบ และจัดระเบียบชุด ROM ของคุณ แล้วส่งต่อให้ FinalBurn Neo เป็นผู้จำลองการทำงานจริง โปรแกรมจำลองเป็นโครงการแยกที่มีทีมงานของตัวเอง — ตัวเปิดเกมสามารถดาวน์โหลดเวอร์ชันล่าสุดให้คุณได้

บนลินุกซ์ เราไปไกลกว่านั้นอีกขั้น: ทีมงาน FinalBurn Neo เองไม่ได้ดูแลบิลด์ SDL2/Linux อีกต่อไป ซึ่งเงียบๆ หยุดสร้างรายชื่อเกมสำหรับบางระบบ (Game Boy Advance, Bally Astrocade) เราติดตามซอร์สโค้ดต้นทางของพวกเขาทุกวันและเผยแพร่บิลด์ของเราเองพร้อมการแก้ไขนี้ เพื่อให้ทุกระบบพร้อมใช้งานตั้งแต่แรก

การจัดการ ROM

ขั้นตอนการทำงานแบบ RomVault ในตัว

ROM ทุกไฟล์ถูกตรวจสอบด้วยการคำนวณ CRC32 ใหม่แล้วเทียบกับไฟล์ DAT อย่างเป็นทางการของ FinalBurn Neo — ไม่เคยเชื่อชื่อไฟล์หรือค่าที่บันทึกไว้ในไฟล์บีบอัด

  • ตรวจสอบความสมบูรณ์ของ ROM ด้วยการตรวจ CRC จาก DAT
  • ตรวจจับ ROM ที่ขาดหาย เสียหาย หรือไม่สมบูรณ์
  • สร้างชุดใหม่โดยอัตโนมัติจากคลังที่มีอยู่
  • นำเข้า ROM แบบเรียกซ้ำ
  • สร้างรายงาน ROM ที่ขาดหายและรายงานตรวจสอบ
  • แสดงข้อมูลโคลน/ต้นฉบับโดยตรงจาก DAT
  • ค้นหา ROM ที่ซ้ำกันในคลังของคุณ
  • ทุกชุดจะถูกตรวจสอบก่อนไปอยู่ในกล่องขาออก

ตรวจสอบ CRC จริง

ทุกรายการในทุกไฟล์บีบอัดจะถูกคลายและคำนวณ CRC32 ใหม่ แล้วเทียบกับ DAT ไฟล์บีบอัดที่เสียหายจึงไม่อาจแอบอ้างว่าใช้งานได้

🔬

ตรวจสอบคลังเกม

บอกคุณว่าชุดไหนเสียหาย และไฟล์ใดเป็นต้นเหตุ ด้วยคำตัดสินสี่แบบที่ชัดเจน

  • ปกติ — ชื่อถูก ข้อมูลถูก
  • ชื่อผิด — ข้อมูลถูกแต่ตั้งชื่อผิด
  • เสียหาย — มีไฟล์อยู่แต่เนื้อหาไม่ตรง
  • ขาดหาย — ไม่มีอยู่ในชุดเลย
📥

ซ่อมจากกล่องเข้า → กล่องออก

วางไฟล์ที่ดาวน์โหลดไว้ในโฟลเดอร์ขาเข้าแล้วกดวิเคราะห์ ชุดที่ครบถ้วนจะถูกย้าย ส่วนชุดที่เสียหายจะถูกประกอบใหม่จากชิ้นส่วนที่พบทั้งในไฟล์ดาวน์โหลดและในคลังเกมเดิมของคุณ

🛡️

ไม่มีการเขียนทับคลังเกมของคุณ

คลังเกมถูกใช้เป็นแหล่งชิ้นส่วนแบบอ่านอย่างเดียวเท่านั้น ผลลัพธ์จะไปอยู่ในโฟลเดอร์ขาออกแยกต่างหากที่จำลองโครงสร้าง DAT กรณีแย่ที่สุดก็เพียงลบโฟลเดอร์นั้นทิ้ง

🗜️

zip, 7z, rar, tar

อ่านได้ทุกอย่างที่คุณดาวน์โหลดมา รวมถึงไฟล์ 7z แบบ solid ที่ดึงออกมาในรอบเดียว และเขียนออกเป็นชุด ZIP ที่สะอาดและแบนราบเสมอ ซึ่งเป็นรูปแบบเดียวที่โปรแกรมจำลองอ่านได้

⚡

สแกนแบบเพิ่มทีละส่วน

ฐานข้อมูล SQLite ในเครื่องพร้อมแคชที่อ้างอิงตามเนื้อหา การสแกนซ้ำจะแตะเฉพาะไฟล์ที่ขนาดหรือเวลาเปลี่ยนไป และการอัปเดต DAT จะตรวจซ้ำเฉพาะชุดที่เปลี่ยนแปลงจริง

📋

รายงานที่ส่งออกได้

บันทึกรายการ ROM ที่ขาดหายหรือผลตรวจสอบทั้งหมดเป็นรายงานข้อความ จัดกลุ่มตามระบบ พร้อม CRC และขนาดของทุกไฟล์ที่คุณยังต้องหา

เครื่องมือ DAT

สร้างไฟล์ DAT จากไฟล์โปรแกรม FinalBurn Neo ของคุณโดยตรง รีเฟรชฐานข้อมูล หรือดาวน์โหลด FBNeo เวอร์ชันล่าสุด — ทำได้ทั้งหมดจากในแอป

พีซีเกม Linux และ SteamOS

เข้ากันได้ดีกับห้องนั่งเล่น

สร้างขึ้นสำหรับเครื่องเล่นเกม Linux และระบบ SteamOS ข้างโซฟา: หน้าจอเดสก์ท็อปของจริงที่ควบคุมด้วยคีย์บอร์ดและเมาส์ ส่วนจอยเอาไว้เล่นเกม

🎮

SteamOS และ Steam Machine (Steam Box)

SteamOS ใช้ฐาน Arch โดยพาร์ทิชันระบบเป็นแบบอ่านอย่างเดียว Flatpak จึงเป็นวิธีติดตั้งซอฟต์แวร์เดสก์ท็อปที่รองรับอย่างเป็นทางการ ชุด Flatpak ติดตั้งลงในโหมดเดสก์ท็อปได้ทันที ไม่ต้องปลดล็อกระบบและไม่ต้องยุ่งกับ pacman

🕹️

คีย์บอร์ดและเมาส์ไว้ค้นหา จอยไว้เล่น

การค้นหาจากเกม 25,000 เกมเป็นงานของคีย์บอร์ด และตัวเปิดเกมถูกออกแบบมาเพื่อสิ่งนี้ เกมจะเริ่มโดยเปิดใช้งานจอยสติ๊กไว้แล้ว พร้อมบันทึกและใช้โปรไฟล์จอยซ้ำได้

📺

สองคลิกจากรายการถึงตัวเกม

ไม่ต้องไล่เมนูซ้อนกันหลายชั้น: ค้นหา คลิก แล้วเล่น เพิ่มตัวเปิดเกมเข้า Steam เป็นเกมนอก Steam แล้วเรียกใช้จากโหมดเกมได้เช่นกัน

จากซอร์สโค้ด

สามคำสั่งบน Debian หรือ Ubuntu

# 1 — dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 — build
git clone https://github.com/battousai90/fbneo-launcher.git
cd fbneo-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 — run
cd build && ./fbneo-launcher

อยากได้แพ็กเกจมากกว่า? ./scripts/package.sh จะสร้าง AppImage, .deb, ไฟล์ tar และ Flatpak bundle ไว้ใน dist/ — เป็นสคริปต์เดียวกันกับที่เวิร์กโฟลว์เผยแพร่ใช้
