Gebaut für den Emulator FinalBurn Neo

FBNeo Launcher ist ein Frontend: Er findet, prüft und ordnet deine ROM-Sets und übergibt sie dann an FinalBurn Neo, das die eigentliche Emulation übernimmt. Der Emulator ist ein eigenständiges Projekt mit eigenem Team — der Launcher kann die neueste Version für dich herunterladen.

fbneo.com FinalBurn Neo auf GitHub

Die Bibliothek

Für Sammlungen, die dem Dateimanager entwachsen sind

Fünfundzwanzigtausend Sets öffnen sich sofort, weil Zeilen erst beim Scrollen aufgebaut werden und jeder Scan nur das erneut liest, was sich auf der Platte wirklich geändert hat.

ROM-Verwaltung

Ein RomVault-artiger Ablauf, eingebaut

Jede ROM wird geprüft, indem ihre CRC32 gegen die offiziellen FinalBurn-Neo-DAT-Dateien neu berechnet wird — niemals über einen Dateinamen oder den im Archiv gespeicherten Wert.

  • Prüft die ROM-Integrität per CRC-Abgleich mit den DAT-Dateien
  • Erkennt fehlende, beschädigte oder unvollständige ROMs
  • Baut Sets automatisch aus Ihrer vorhandenen Bibliothek neu auf
  • Importiert ROMs rekursiv
  • Erzeugt Berichte zu fehlenden ROMs und zur Prüfung
  • Zeigt Klon-/Parent-Infos direkt aus dem DAT
  • Findet doppelte ROMs in Ihrer Bibliothek
  • Jedes Set wird geprüft, bevor es im Ausgang landet

Echte CRC-Prüfung

Jeder Eintrag jedes Archivs wird entpackt und seine CRC32 neu berechnet, dann mit dem DAT abgeglichen. Ein beschädigtes Archiv kann sich nicht als gültig ausgeben.

🔬

Bibliotheks-Prüfung

Sagt dir, welche Sets defekt sind und welche Datei schuld ist, mit vier klaren Urteilen.

  • OK — richtiger Name, richtige Daten
  • Falscher Name — richtige Daten, falsch benannt
  • Beschädigt — vorhanden, aber falscher Inhalt
  • Fehlt — gar nicht im Set
📥

Eingang → Ausgang-Reparatur

Lege Downloads in einen Eingangsordner und klicke Analysieren. Vollständige Sets werden verschoben, defekte aus Teilen neu aufgebaut, die in deinen Downloads und in deiner vorhandenen Bibliothek gefunden werden.

🛡️

Deine Bibliothek wird nie verändert

Sie dient nur als schreibgeschützter Teilevorrat. Ergebnisse landen in einem separaten Ausgangsordner, der die DAT-Struktur abbildet: schlimmstenfalls ein Ordner, den du löschen kannst.

🗜️

zip, 7z, rar, tar

Liest, was du heruntergeladen hast — auch solide 7z-Archive, in einem einzigen Durchlauf geleert. Schreibt immer saubere, flache ZIP-Sets, das einzige Format, das der Emulator lädt.

⚡

Inkrementelles Scannen

Eine lokale SQLite-Datenbank mit inhaltsadressiertem Cache. Erneute Scans berühren nur Dateien, deren Größe oder Zeitstempel sich geändert hat; ein DAT-Update prüft nur die wirklich veränderten Sets erneut.

📋

Exportierbare Berichte

Speichere die Liste fehlender ROMs oder die vollständige Prüfung als Textbericht, nach System gruppiert, mit CRC und Größe jeder noch fehlenden Datei.

🔄

DAT-Werkzeuge

Erzeuge DAT-Dateien direkt aus deiner FinalBurn-Neo-Binärdatei, aktualisiere die Datenbank oder lade die neueste FBNeo-Version — alles aus der Anwendung heraus.

Linux-Gaming-PCs und SteamOS

Zu Hause im Wohnzimmer

Gebaut für Linux-Spielerechner und SteamOS-Systeme am Sofa: eine echte Desktop-Oberfläche, die du mit Tastatur und Maus bedienst, während der Controller fürs Spiel selbst bereitsteht.

🎮

SteamOS und Steam Machine (Steam Box)

SteamOS basiert auf Arch mit einer schreibgeschützten Systempartition — Flatpak ist dort deshalb der unterstützte Weg, Desktop-Software zu installieren. Das Flatpak-Bundle landet direkt im Desktop-Modus, ohne Systemsperre aufzuheben und ohne pacman.

🕹️

Tastatur und Maus zum Stöbern, Pad zum Spielen

25.000 Spiele zu durchsuchen ist Tastaturarbeit, und genau darauf ist der Launcher ausgelegt. Spiele starten mit bereits aktiver Joystick-Unterstützung, Controller-Profile werden gespeichert und wiederverwendet.

📺

Zwei Klicks von der Liste ins Spiel

Keine verschachtelten Menüs: suchen, klicken, spielen. Füge den Launcher als Nicht-Steam-Spiel zu Steam hinzu, dann ist er auch im Game-Modus erreichbar.

Aus dem Quellcode

Drei Befehle unter Debian oder Ubuntu

# 1 — dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 — build
git clone https://github.com/battousai90/fbneo-launcher.git
cd fbneo-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 — run
cd build && ./fbneo-launcher

Lieber die Pakete? ./scripts/package.sh erzeugt das AppImage, das .deb, das Tar-Archiv und das Flatpak-Bundle in dist/ — genau das Skript, das auch der Release-Workflow ausführt.
